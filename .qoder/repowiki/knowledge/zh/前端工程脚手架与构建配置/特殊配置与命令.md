`npm run dev` 启动 Vite 开发服务器，默认代理 `/api` 到 `http://10.125.48.192:8082`；`npm run build` 并行执行 `type-check`（`vue-tsc --build --force`）与 `build-only`（`vite build --mode prod`）；`npm run test:unit` 运行 Vitest；`npm run lint` 与 `npm run format` 分别触发 ESLint 修复与 Prettier 格式化；`npm run prepare` 自动执行 `husky install` 安装 Git hooks。
