本模块为仓库根的工程骨架，不包含业务源码（src/ 在外部），职责是定义项目的构建与开发工具链：
- 构建入口 `vite.config.ts` 启用 `@vitejs/plugin-vue`、`vite-plugin-pages`（路由按 `src/views` 文件生成）、`unplugin-vue-components`（自动按需引入 Ant Design Vue）、`vite-plugin-svg-icons`（从 `src/assets/icons` 注入 SVG Sprite）以及 `vite-plugin-top-level-await`；通过 PostCSS 串联 TailwindCSS 与 Autoprefixer，并在 SCSS 中全局注入 `@styles/variables.scss`。
- 测试由 `vitest.config.ts` 继承 vite 配置并切换 `environment: 'jsdom'`，使用 `@vue/test-utils` 进行单元测试。
- TypeScript 采用多 tsconfig 拆分：`tsconfig.json` 聚合 `tsconfig.app.json` / `tsconfig.node.json` / `tsconfig.vitest.json`，应用代码走 `tsconfig.app.json`（extends `@vue/tsconfig/dom`，启用 `composite` 增量编译，路径别名 `@/*` → `./src/*`）。
- 样式体系以 TailwindCSS 为主，`tailwind.config.js` 扩展了 `gray`/`picker`/`hover` 三色；Ant Design Vue 通过 CSS-in-JS 模式集成。
- 代码质量由 `.eslintrc.cjs`、`.prettierrc.json`、`lint-staged`（仅对 `src/**/*.{js,ts,vue}` 运行 prettier）共同约束。
- Git 钩子通过 `husky install` 安装，`scripts/verifyCommit.js` 作为 commit-msg hook 校验提交信息遵循 Conventional Commits（feat/fix/docs/dx/refactor/perf/test/workflow/build/ci/chore/types/wip/release/deps）或 `v\d*` 发布格式。
- 环境变量目录位于 `env/`（`envDir: './env'`），类型声明集中在 `env.d.ts`。
